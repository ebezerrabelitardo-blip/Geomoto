# Projeto APK

Como gerar o APK sem instalar nada:

1. Crie um repositório no GitHub (pode ser privado).
2. Envie todos os arquivos desta pasta (Add file > Upload files).
3. Abra a aba Actions > Build APK > Run workflow.
4. Quando terminar (uns 5 a 10 minutos), baixe o artefato app-debug-apk.
5. Descompacte e instale o app-debug.apk no celular (permita instalar de fontes desconhecidas).

Observação: jogos 3D carregam o three.js da internet, então precisam de conexão.
